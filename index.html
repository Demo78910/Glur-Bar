ตั้งค่า GLUR BAR บน iPhone

ไฟล์ HTML นี้รวมโค้ดหน้าเว็บ SQL และ Edge Function ไว้ในไฟล์เดียว แต่ยังต้องติดตั้งฐานข้อมูลและฟังก์ชันบน Supabase ก่อนใช้งานจริง

1. สร้างโปรเจกต์ Supabase ใหม่ → SQL Editor → คัดลอก SQL ด้านล่างแล้ว Run

ดู SQL

2. สร้าง Owner ใน Authentication และรัน SQL ตั้งค่า Owner ตามคู่มือ

3. สร้าง Edge Function ชื่อ manage-user และคัดลอกโค้ดด้านล่าง

ดู Edge Function

4. ตั้งค่า Project URL และ anon/publishable key ใน CONFIG ภายใน HTML นี้ แล้วอัปโหลดไฟล์เดียวไป GitHub Pages
